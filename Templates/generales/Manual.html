🏠 Introducción a la App Puestos CAB

¿Qué es Puestos CAB?

El Sistema Puestos CAB es una aplicación web diseñada para gestionar y controlar los procesos de producción en las cabinas de trabajo de EMESA. Permite el seguimiento en tiempo real de las órdenes de trabajo, visualización del estado de las órdenes y análisis de eficiencia.

Características principales:

🔄 Tiempo Real

Seguimiento instantáneo del estado de las órdenes de trabajo y actualización automática de datos.

📊 Control

Registro de piezas hechas, faltantes y en proceso>

📈 Análisis de Eficiencia

Métricas de rendimiento, comparación con objetivos y reportes de productividad.

👥 Multi-Usuario

Sistema de permisos por roles con acceso diferenciado según el nivel del usuario.

Niveles de Usuario

Tu nivel actual:

Descripción de niveles:

  • Nivel 1 (Operario): Acceso básico a gestión de órdenes de trabajo
  • Nivel 2+ (Jefe de Equipo y Superior): Acceso completo incluyendo configuración de capacidades, creación de puestos, indicadores y supervisión

Navegación General

  1. Utiliza las tarjetas del menú principal para acceder a las diferentes secciones
  2. El widget de usuario (esquina inferior derecha) muestra tu información y permite cerrar sesión
  3. Cada pantalla incluye filtros y búsquedas para encontrar información específica
  4. Los datos se actualizan automáticamente - no es necesario recargar la página

🔧 Puesto CAB - Gestión de Órdenes

Propósito

La pantalla Puesto CAB es donde los operarios gestionan las órdenes de trabajo, registran el progreso y registran faltantes.

Cómo usar Puesto CAB:

  1. Seleccionar Puesto: Haz clic en la tarjeta del puesto donde vas a trabajar
  2. Configurar Filtros: Selecciona años y semanas para filtrar las órdenes relevantes
  3. Cargar Órdenes: Presiona "Aplicar Filtros" para ver las órdenes disponibles
  4. Gestionar Estados: Utiliza los botones de Estado para marcar el progreso

Estados de las Órdenes

✅ Hecho

Marca una pieza como completada correctamente. Se suma a la producción total.

❌ Faltante

Registra una pieza faltante para hacer la OF. Requiere descripción del faltante.

🔄 En Proceso

Indica que has trabajado parcialmente en esta orden pero no está cerrada y por tanto, no puedes marcar Hecho.

📊 Gestión de Capacidades

🔐 Acceso Restringido: Esta función está disponible para usuarios de nivel Jefe de Equipo (2+) o superior.

Propósito

La gestión de capacidades permite configurar los objetivos de producción por puesto, turno y fecha. Estos valores se utilizan para calcular las eficiencias y generar los indicadores de rendimiento.

Tipos de Configuración

📅 Por Fecha Específica

Configura capacidades para una fecha y turno concretos. Su función es ajustar capacidad en días que el operario trabaja en la sección pero no con su capacidad habitual.

🔄 Jornada Fija

Establece una capacidad estándar que se aplicará como base para el puesto.

Cómo configurar capacidades:

  1. Fijar Jornada Elige el tipo de configuración
  2. Fecha y Turno: Selecciona la fecha y turno específicos
  3. Operario: Selecciona Operario del desplegable. En caso de Fecha específica solo aparecen los operarios que tienen algún fichaje en el turno concreto.
  4. Capacidad: Ingresa la capacidad objetivo en minutos
  5. Guardar: Confirma la configuración
⚠️ Nota: Las capacidades se expresan en minutos.

Validación y Control

  • Se puede consultar la capacidad existente antes de modificarla
  • Las capacidades se utilizan automáticamente en el cálculo de eficiencias
  • Los cambios se reflejan inmediatamente en los indicadores

📈 Panel de Indicadores

🔐 Acceso Restringido: Esta función está disponible para usuarios de nivel Jefe de Equipo (2+) o superior.

Propósito

El panel de indicadores proporciona una vista del rendimiento de todos los operarios, mostrando eficiencias de turno

Cómo usar los Indicadores:

  1. Seleccionar Fecha y Turno: Configura el período de análisis
  2. Visualizar Tarjetas: Cada puesto se muestra con su eficiencia calculada
  3. Interpretar Colores: Verde (>85%), Amarillo (70-85%), Rojo (<70%)
  4. Analizar Datos: Identifica puestos con bajo rendimiento

Métricas Disponibles

⏱️ Minutos Teóricos

Tiempo real de trabajo registrado en el sistema para el turno seleccionado.

🎯 Capacidad Configurada

Objetivo de minutos establecido para el puesto en ese turno específico.

📊 Eficiencia (%)

Porcentaje calculado: (Minutos Teóricos / Capacidad) × 100

🚦 Estado Visual

Código de colores para identificación rápida del rendimiento.

💡 Análisis Recomendado:
  • Revisa diariamente los indicadores de cada turno
  • Identifica patrones de bajo rendimiento
  • Pregunta a los operarios por posibles tiempos teoricos incorrectos en piezas concretas
  • Compara eficiencias entre operarios en el mismo puesto
  • Usa los datos para tomar decisiones de mejora

Interpretación de Resultados

  • Verde (>85%): Rendimiento óptimo, puesto cumpliendo objetivos
  • Amarillo (70-85%): Rendimiento aceptable, revisar posibles mejoras
  • Rojo (<70%): Rendimiento bajo, requiere atención inmediata
  • Gris (Sin datos): No hay información disponible para el período

⚙️ Configuración del Sistema

🔐 Acceso Restringido: Esta función está disponible para usuarios de nivel Jefe de Equipo (2+) o superior.

Propósito

La sección de configuración permite la gestión completa de puestos de trabajo, incluyendo la creación, modificación y eliminación de puestos, así como la configuración de las columnas que se mostrarán en cada uno.

Gestión de Puestos

Crear Nuevo Puesto:

  1. Introduce nombre de puesto
  2. Elige un color identificativo para la pantalla
  3. Selecciona el Código de puesto
  4. Selecciona las columnas que se mostrarán y ordénalas con las flechas
  5. Guarda la configuración

Modificar Puesto Existente:

  1. Busca el puesto en la lista
  2. Actualiza los campos necesarios, añade o reorganiza las columnas
  3. Confirma los cambios

Configuración de Columnas

📋 Columnas Disponibles

El sistema obtiene automáticamente todas las columnas disponibles de la base de datos.

🎯 Selección Personalizada

Cada puesto puede mostrar diferentes columnas según sus necesidades operativas.

📊 Orden Configurable

Las columnas se pueden reordenar para optimizar el flujo de trabajo.

🎨 Colores Personalizados

Asigna colores específicos para identificar visualmente cada puesto.

⚠️ Precauciones:
  • Eliminar un puesto puede afectar datos históricos
  • Consulta con Digitalización antes de realizar cambios importantes

Buenas Prácticas

  • Nomenclatura: Usa nombres descriptivos y códigos consistentes
  • Columnas: Incluye solo las columnas necesarias para evitar sobrecarga visual
  • Colores: Elige colores contrastantes y fáciles de distinguir
  • Respaldos: Informa a las personas afectadas por los cambios realizados (Usuarios App)

📦 Resumen de Pedidos

🔐 Acceso Restringido: Esta función está disponible para usuarios de nivel Jefe de Equipo (2+) o superior.

Propósito

El Resumen de Pedidos proporciona una vista consolidada de todos los pedidos en el sistema, permitiendo seguimiento de progreso.

Características Principales

📊 Vista Consolidada

Visualiza todos los pedidos con información detallada de estado.

🔍 Filtros Avanzados

Filtra por fechas, puestos, estados y múltiples criterios simultáneamente.

Cómo usar Resumen de Pedidos

  1. Aplicar Filtros: Selecciona el rango temporal y criterios de búsqueda
  2. Cargar Datos: El sistema carga automáticamente la información filtrada
  3. Analizar Resultados: Revisa los estados de las órdenes de fabricación para cada pedido
💡 Casos de Uso Recomendados:
  • Reuniones de revisión semanal de producción
  • Secuenciación del trabajo de cada puesto
  • Evitar pedidos abiertos por piezas de puestos de la sección

❓ Preguntas Frecuentes

🔧 Problemas Técnicos

❓ Los datos no se cargan o aparecen desactualizados

Solución:

  • Refresca la página (F5)
  • Verifica los filtros aplicados (años, semanas, puestos)
  • Comprueba tu conexión a internet
  • Si persiste, contacta con digitalización

❓ Error al guardar cambios

Solución: Asegúrate de que todos los campos obligatorios estén completados correctamente. Si el error persiste, anota el mensaje de error exacto y repórtalo a digitalización.

📋 Uso del Sistema

❓ ¿Puedo trabajar en múltiples órdenes simultáneamente?

Respuesta: Sí.

❓ ¿Cómo se calculan las eficiencias?

Respuesta: La eficiencia se calcula como: (Minutos Teóricos Registrados / Capacidad Configurada) × 100. Los minutos teóricos provienen del trabajo real registrado en el sistema.

❓ ¿Qué pasa si marco algo como "Faltante" por error?

Respuesta: Puedes desmarcar el checkbox "Faltante" para revertir la acción. El sistema mantiene un historial de cambios para trazabilidad.
